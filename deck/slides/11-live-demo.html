How to swap in a real demo

In deck/manifest.js, change this slide's entry to either:

A local HTML app — drop the file in deck/slides/ and set file: "slides/my-demo.html" + fit: "native"
A live URL — set url: "https://app.freightpop.com" + fit: "native"

With fit: "native" the demo fills the screen at natural size and stays fully interactive — click around it on the big monitor while the presenter view stays on your laptop.
