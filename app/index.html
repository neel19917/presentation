BOOTH SETUP
  1. Set the external monitor to Extended display (Mac: System Settings → Displays · Win: Win+P → Extend).
  2. Open Presenter view here, then click “Open audience window”.
  3. Drag the audience window to the big screen, click it once, press F for fullscreen.
  4. Present: → ← Space navigate · G jump grid · B blackout · A replay animations · P [ ] 1–9 video control.
