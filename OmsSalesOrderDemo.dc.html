Order intake
Five ways an order gets into FreightPOP.
Automated or manual, depending on your technical setup and how the order starts. Every route lands in the same order book.
Captured once. Never re-typed.
01
Automated ERP / WMS integration
FreightPOP polls your system of record — NetSuite, Acumatica, Dynamics 365 Business Central — every 10–15 minutes, importing only the order statuses you configure. They land in Sales Orders for planning, or Outbound Transactions when ready to execute.
02
Real-time live pull
Enter a sales order or load number in the Order Import field on Quote/Ship and FreightPOP queries the ERP by API on demand — no waiting for the next batch cycle.
03
Manual order creation
Add New Order in the grid for one-off transfers and manual sales — or skip the order stage entirely and enter the shipment straight on Quote/Ship.
04
EDI and API
EDI 850 purchase orders and 940 shipping forms from trading partners or an external WMS. Proprietary systems push orders in through the FreightPOP API.
05
FreightPOP Deliveries (FPD)
Picking a partial quantity from a sales order creates an FPD record, which moves into Outbound Transactions for shipping.
